Chromaticity (OKLCh hue / chroma)

Black: not a real colour (outside the spectral locus, outlined; picks snap to its edge). Darkened: real but outside sRGB (display only). Shaded: at this brightness the bulb has to desaturate (light) or cannot reach this brightness even as white (dark). Triangle: bulb RGB gamut; line: CW–WW; ○ target, ● predicted output. Rings: chroma every 0.05; spokes: hue every 30°. Shift-drag keeps the hue, Alt-drag keeps the chroma. The plane is the canonical Lemtone chromaticity: OKLab a, b at L = 1, so chroma is OKLCh C at L 1.

Sends on every change, one command at a time (waits for the base> prompt). lt sends the Lemtone value and the bulb runs the solver; setraw sends this page's duties and periods. Both should give identical light. A range sends ltrange (every bulb solves for itself); setraw has one target on the base station, so it only addresses the first id. Stop sends ltclr for the range / setraw off; bulbs fall back to their default 15 s later. Changing the range while live clears the old one first.

A channel's period grows from n min until it gets res. ticks of on-time, capped by total lumens (first tier exceeded wins, else n max). Stateless: the same value always gives the same periods. Changes here affect this page only; the bulb uses the compiled defaults.
